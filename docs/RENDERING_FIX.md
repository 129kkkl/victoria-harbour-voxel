# 远景黑方块闪烁修复

2026-10-11。症状：启动后的维港远景间歇出现覆盖画面的黑块，近景不明显。

## 根因与复现

渡轮尾迹在片元着色器中直接计算 `pow(vUv.y, 1.2)`。远景的尾迹三角形非常窄，MSAA 边缘片元的插值坐标可能超出 0–1。负数的小数次幂生成 NaN，透明混合将其写入 HDR 场景，泛光逐级模糊再把异常扩散成大片黑块。

在本机 NVIDIA RTX 4060 Laptop / ANGLE D3D11 上，旧版生产远景的 48 帧采样中检测到 10 帧含非有限值。隐藏四艘船的尾迹后，94 帧采样没有异常；只修复幂运算输入后，238 帧采样没有异常。此对比保留原有 HDR、MSAA 和泛光设置。

这是着色器的数值边界错误，生产 HTTP 版本也能复现，不是单文件缺少资源。

## 修复

- 尾迹 UV 限制在 0–1 内，再计算小数次幂；输出透明度同样限制在 0–1。
- 将尾迹、岸线、天空中的反向 `smoothstep` 改为有序区间的 `1 - smoothstep(...)`，去除未定义运算。
- 水面菲涅尔的法线点积同时限制上下界，防止浮点误差产生负的幂运算底数。
- 保留渡轮、泛光和抗锯齿，重新构建生产版与离线单 HTML。

MSAA 插值可越出图元的规则见 [Khronos 多重采样说明](https://wikis.khronos.org/opengl/Multisample)，幂函数与平滑阶跃的定义见 [GLSL 规范](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html)。

## 回归检查

`tools/verify-rendering.js` 直接使用当前尾迹着色器，在真实 GPU 上强制输入越界 UV，并逐帧读取场景和各级泛光的半浮点缓冲，检查 NaN/Infinity。重新引入旧边界算法的对照产生 704 个非有限通道值；修复版为 0，透明度合法且尾迹仍可见。

开发预览的浏览器控制台可运行：

```js
const { verifyRendering } = await import('/tools/verify-rendering.js');
await verifyRendering(window.__vh);
```
