# 维港城市品质升级方案

日期：2026-10-11。目标：从重复的建筑盒体升级为有街区性格、空间秩序和细节层级的可探索城市沙盘。

## 诊断

- 所有普通楼宇共享按高度分段的退台逻辑，体型和屋顶轮廓高度相似。
- 单栋楼几乎占满街区，裙房还会向道路外扩；多个城区各自铺网格，交界出现重叠。
- 立面细节依赖小幅重复纹理，没有形成楼栋之间不同的结构节奏。
- 环境缺少树木、街道细节和港口活动；界面主要暴露调试数据，探索入口不足。

## 本轮实施

| 层面 | 改造内容 | 验收标准 |
| --- | --- | --- |
| 建筑 | 独立、确定性的建筑语法；细长塔、切角塔、错层塔、双塔、板式住宅、院落、唐楼、工业楼、阶梯楼；局部细部实例化 | 至少 8 种轮廓；跨种子稳定生成；构件不越出地块 |
| 街区 | 城区归属、旋转地块碰撞检查、真实退界、窄面宽拆分、开放空间 | 无楼栋占地重叠；沿海角点合法；每区仍有建筑 |
| 立面 | 连续楼层相位、逐楼差异、玻璃环境反射、局部窗光随机；招牌集中在沿街底层 | 无六层一次的整楼霓虹横带；昼夜均可辨识体型 |
| 环境 | 庭院与街边树、口袋绿地、道路标线、程序化渡轮与航迹 | 植被落地；船只在水域内；实例批次受控 |
| 体验 | 新版全屏界面、观景点、平滑相机、巡游、光照天气、画质、截图、响应式布局 | 全部入口可操作；键盘焦点正确；小屏无横向溢出 |
| 工程 | 空间分块与细节距离控制、降低无效逐帧工作、离线单文件输出 | 原有地理/地标/光影检查通过；新增空间与语法检查；实机截图 |

## 实施次序

1. 先修复空间布局与建筑生成，再调整材质与环境。
2. 新界面连接真实场景状态；所有按钮均接入实际功能。
3. 执行数值检查、生产构建、浏览器白天/夜间/小屏验证，保存截图和结果。

## 边界

这是程序化、示意性的维港沙盘，继续保留离线运行和已有 32 座地标。地标原始参数不是测绘数据，本轮不声称修复全部地理精度；可进入室内和完整第一人称碰撞系统属于后续独立功能。

### 本轮重点修复

- 以地标实际几何生成定向包围盒，普通建筑、绿地和道路避开地标占地，替代过宽的圆形留白。
- 地块碰撞使用空间索引和旋转矩形；建筑构件、裙房和邻栋保持退界。三个种子均检查通过。
- 修复墙角明暗计算导致整面墙发黑的问题，取消反复横切整栋楼的霓虹带，增加 16 类中文街铺招牌。
- 地形重复高度采样改为网格缓存；核心/远景网格为 16m/32m。城市地面纹理限制在城区，山体增加细纹理并随夜晚压暗。
- 海面降低尖锐白色高光和波纹噪声；夜间降低普通窗光与泛光，保留少量亮窗和街道光池。
- 启动阶段通过 MessageChannel 主动让出线程，避免后台动画帧节流拖慢加载。细节以 512m 空间块管理，根据画质和相机距离显示。
- 完成三个画质档位、可导出的 PNG、移动端折叠面板和键盘焦点处理；单文件构建同步内联新的 CSS。

## 追加：中环与九龙街区性格细化（2026-10-11）

这次继续减少普通建筑的盒子感，将差异落实到实际几何、店铺与街道构件。中环的四种新塔楼以收分切角、椭圆平面、斜屋顶和连接双体为主要轮廓，附带玻璃幕墙、斜撑、空中花园、入口雨棚和退入的大厅。九龙旧城拆成唐楼、骑楼、圆角街楼、退台旧楼四类，并改变开间、阳台分布、颜色和临街方向。

每个旧城地块有独立店面与中文招牌，添加条纹雨棚、空调和支架、晾衣、落水管、屋顶棚屋、圆筒水箱；部分旧楼配消防梯。屋顶采用四类设施组合，按楼栋改变棚屋和水箱的大小、位置，部分加入露台绿植与座椅；水箱必须完整落在支撑屋顶内。人行道空地补入候车亭、长椅、垃圾桶和护栏，所有设施均检查车道、楼栋、地标、岸线与地形高差。九龙观景点移近普通街楼，便于直接观察这些细节。

默认种子仍为 6,157 栋建筑，现包含 16 类轮廓。其中新现代塔楼 242 栋（收分 63、椭圆 77、斜冠 54、连廊 48），旧街四类共 2,712 栋（唐楼 681、骑楼 706、圆角 620、退台 705）。中环新现代类型占比在三个测试种子中均超过 70%。人行道设施为 93 处候车亭、362 张长椅、362 个垃圾桶、269 段护栏，另有 114 处斑马线。

所有新几何采用共享实例批次，细节继续按 512m 分块并按画质和相机距离裁剪。切换观景点立即更新细节可见性。新增曲面和斜冠使用缩放后的正确法线区分墙面与屋面，避免斜面错误覆盖屋顶材质。完整城市、地标和公共空间库存约 545 万三角面，高于首轮约 278 万；实际绘制受视锥和距离裁剪影响，帧率仍需根据设备选择画质。

验收：174 项数值和生成检查通过（建筑专项增至 26 项），涵盖三个种子的占地、确定性、城区类型覆盖、店铺与屋顶设施、街道避让，以及共享几何闭合、正向体积和有限法线。32 座地标规格检查无问题；生产与离线单文件构建成功，单文件约 0.83 MiB。

最终生产构建复测六个场景组合：维港远景、鸟瞰、中环、九龙街巷、夜港、雨天鸟瞰，共 208 帧覆盖渡轮完整航线。HDR 与泛光缓冲无异常浮点像素、无 WebGL 错误，尾迹越界输入测试通过，先前的远景黑块修复继续有效。GPU 记录（历史本地材料，未随公开源码提供）。生产页面控制台无错误或警告，本次启动约 2.06 秒，仅作为本机观测；生产统计（历史本地材料，未随公开源码提供）。离线文件为 875,649 字节，已确认 JS/CSS 与生产资源逐字一致、无外链脚本或样式；内联检查（历史本地材料，未随公开源码提供）。
