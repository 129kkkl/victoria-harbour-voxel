# 维多利亚港 · 城市图景

Three.js + Vite 的程序化维港沙盘。17 个城区、6,157 栋普通楼宇、32 座示意地标，全部几何与纹理在本地生成，不依赖在线地图、外链字体或模型服务。

## 本轮品质升级

- **16 种建筑轮廓**：中环加入收分晶体塔、椭圆空中花园塔、斜冠办公塔和连廊双塔；旧城采用唐楼、骑楼、圆角街楼与退台旧楼。配合原有住宅、院落等类型，按城区选择造型、材质和屋顶，减少整片复制感。
- **街铺与生活细节**：独立中文店招、退入的店面、条纹雨棚、错落阳台、空调、晾衣、消防梯和圆筒水箱；候车亭、长椅、垃圾桶、护栏与斑马线补足街道尺度。
- **重新组织街区**：地块归属、旋转包围盒检测、真实地标占地避让、裙房退界、唐楼窄面宽拆分和旧城楼高限制。231 处绿地、6,478 棵树补充街道层次。
- **重做材质与环境**：连续楼层纹理、玻璃环境反射、独立窗光、沿街中文招牌，调整海水、山体与夜景亮度；4 艘渡轮沿两条水上路线行驶。
- **完整探索界面**：6 个观景点、平滑镜头切换、自动巡游、5 组时间预设、4 种天气、3 档画质、PNG 截图、键盘操作与手机布局。
- **工程优化**：细节空间分块和距离裁剪、共享实例几何、合并船只几何、地形高度采样复用、避免后台页面加载依赖动画帧。

完整诊断、实施方案与验收记录见 [升级方案](docs/UPGRADE_PLAN.md)。此前 M1–M4 记录保存在 [历史里程碑](docs/LEGACY_MILESTONES.md)，其中旧统计及旧操作方式不再代表当前版本。

## 运行与构建

```bash
npm install
npm run dev                  # 开发预览 http://localhost:5173
npm run build                # 生产产物 dist/
npm run preview              # 生产预览 http://localhost:4173
npm run build:single         # 单文件 dist-single/victoria-harbour.html
```

离线 HTML 约 0.83 MiB，包含 JavaScript、CSS 和所有程序化资源，可下载到本机后用支持 WebGL2 的浏览器打开。当前验收已确认内联资源完整、生产 HTTP 页面正常；验证浏览器只允许 HTTP/HTTPS，未直接执行 `file://` 打开测试。

## 操作

| 操作 | 功能 |
| --- | --- |
| 左键拖拽 / 单指 | 环绕 |
| 右键拖拽 / 双指拖动 | 平移 |
| 滚轮 / 双指缩放 | 缩放 |
| W A S D / Q E | 平移 / 升降 |
| 数字 1–6 | 切换观景点 |

首次进入为当日香港时间 16:36 的场景。点击“此刻”同步实际香港日期与时间；“截图”导出纯场景 PNG。小屏可横向滑动观景点列表，光照与天气面板默认收起。系统开启减少动态效果时，镜头直接切换。

2026-10-11：174 项检查通过、地标规格检查 0 个问题、生产构建及单文件构建通过。本次建筑细化后，6 个场景组合共 208 帧 GPU 检查通过，HDR 与泛光缓冲无 NaN/Infinity、无 WebGL 错误，记录见 rendering-checks.json（历史本地材料，未随公开源码提供）。此前完整界面交互及 390/360px 布局检查见 browser-checks.json（历史本地材料，未随公开源码提供）。

## 主要代码入口

| 文件 | 职责 |
| --- | --- |
| `src/city/streetGrid.js` / `spatial.js` | 城区归属、地块划分、道路和占地检测 |
| `src/city/architecture.js` / `districtArchitecture.js` | 确定性的逐栋建筑与城区造型规则 |
| `src/city/architectureGeometry.js` | 收分、曲面、斜冠与斜撑的共享几何 |
| `src/city/buildings.js` / `facades.js` | 实例化几何、距离细节、立面与招牌 |
| `src/city/publicRealm.js` / `streetFurniture.js` | 街树、庭院、绿地、街道设施和道路标线 |
| `src/city/heightfield.js` | 地形高度场与山体材质 |
| `src/water/ferries.js` / `harbour.js` | 渡轮、航迹与海面 |
| `src/camera/views.js` / `orbit.js` | 观景点、镜头运动与巡游 |
| `src/ui/hud.js` / `hud.css` | 场景界面与响应式布局 |
| `src/main.js` | 启动、画质、截图、场景更新 |

浏览器控制台 `window.__vh` 提供场景统计、启动耗时与渲染对象，供调试检查。

## 当前边界

这是一座有香港街区特征的程序化沙盘。岸线、山体与地标为示意模型，已有地标参数仍需逐栋核对，不能当作测绘或真实建筑高度数据。当前支持轨道探索，尚未提供室内空间、完整第一人称碰撞、行人或道路交通模拟。帧率取决于设备与画质；界面读数和后台浏览器结果不作为稳定帧率承诺。
